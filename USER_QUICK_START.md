# 📱 User Panel Quick Start Guide

## Welcome to Your Housing Society App!

This guide helps you get the most out of the resident portal.

---

## 🚀 Getting Started

### 1. Login to Your Account
```
URL: http://localhost:3000 (or your deployed URL)
Email: Your registered email
Password: Your password
```

### 2. View Your Dashboard
After login, you'll see:
- ✅ Quick statistics (complaints, permissions, payments, notices)
- ✅ Interactive charts showing your complaint and permission status
- ✅ Quick action buttons for common tasks
- ✅ Recent notices, events, and maintenance records

## 📋 Key Sections

### 1. Dashboard (Home Page)

**What You See:**
- 4 stat cards showing your activity
- Complaint status breakdown (pie chart)
- Permission status breakdown (pie chart)
- Recent notices
- Upcoming events
- Pending maintenance

**Actions You Can Take:**
- Click stat cards to go to that section
- Use quick action buttons to:
  - Raise a complaint
  - Request a permission
  - Pay maintenance

---

### 2. My Complaints

**Purpose**: Track all your complaints to the society

**Available Actions:**
- ✅ **Raise New Complaint** - Click red button
  - Title: What's the problem?
  - Category: Water, Electricity, Maintenance, Other
  - Priority: Low, Medium, High
  - Description: Detailed explanation
  
- ✅ **View All Complaints** - See your history
- ✅ **Track Status** - See where your complaint is
  - 🟡 Pending - Just submitted
  - 🔵 In Progress - Being worked on
  - 🟢 Resolved - Fixed!

**Filtering Options:**
- By Status (Pending, In Progress, Resolved)
- By Priority (Low, Medium, High)
- By Category (Water, Electricity, Maintenance, Other)

**Statistics:**
- Total complaints filed
- How many are pending
- How many in progress
- How many resolved

**Example Workflow:**
```
1. Click "Raise Complaint"
2. Enter complaint details
3. Select category and priority
4. Click Submit
5. Come back to see status updates
```

---

### 3. Permission Requests

**Purpose**: Request permissions from the society (visitors, renovations, etc.)

**Available Actions:**
- ✅ **Request New Permission**
  - Type: What permission you need
  - Title: Brief description
  - Start Date: When you need it
  - End Date: Until when
  - Description: Details
  
- ✅ **Track Requests** - See approval status
- ✅ **View Status** - Check if:
  - 🟡 Pending - Awaiting approval
  - 🟢 Approved - You're good to go!
  - 🔴 Rejected - Resubmit or contact admin

**Statistics:**
- Total requests
- Pending approval
- Already approved
- Rejected requests

**Example Workflow:**
```
1. Click "Request Permission"
2. Select permission type
3. Fill in dates and details
4. Submit
5. Wait for approval
6. Use permission once approved
```

---

### 4. Maintenance Payments

**Purpose**: Track and pay your monthly maintenance charges

**What You See:**
- 📊 Financial Dashboard
  - Total payment records
  - How many pending
  - Already paid
  - Total pending amount due

**How to Pay:**
```
1. Go to Maintenance section
2. See pending payments
3. Click "Pay Now" on the payment
4. Enter amount (auto-filled usually)
5. Complete payment (Razorpay)
6. Receipt is saved
```

**Payment Status:**
- 🟡 Pending - Not yet paid
- 🟢 Paid - Payment received
- 🔴 Overdue - Payment is late

**Tips:**
- ✓ Pay before the due date
- ✓ Keep receipts
- ✓ Check payment history anytime

---

### 5. Events & Fundraisers

**Purpose**: See society events and contribute to fundraisers

**What You Can Do:**
- 👀 **View Events** - See upcoming events
- 💚 **Contribute** - Help with fundraisers
  - Shows progress bar
  - See how much has been collected
  - Know the target amount
  
- 💳 **Make Payment** - Contribute via Razorpay

**Event Details:**
- 📅 Event name and dates
- 📝 Description
- 💰 Target amount
- 📊 Progress bar showing collection %
- 💵 Current vs target amount

**How to Contribute:**
```
1. Browse Events section
2. Find event you want to help
3. Click "Contribute"
4. Enter contribution amount
5. Click "Pay"
6. Complete Razorpay payment
7. Done! Your contribution is recorded
```

## 🎯 Common Tasks

### Task 1: File a Complaint
```
Time: 2-3 minutes

Steps:
1. Go to Dashboard
2. Click "Raise Complaint" button
3. Fill in:
   - Title (e.g., "Water leakage in flat")
   - Category (Water)
   - Priority (High)
   - Description (Details about issue)
4. Click Submit
5. Get instant confirmation
6. Track status anytime
```

### Task 2: Request Visitor Permission
```
Time: 3-4 minutes

Steps:
1. Go to Permissions
2. Click "Request Permission"
3. Fill in:
   - Type (Visitor)
   - Visitor name/details
   - Start date
   - End date
4. Add any notes
5. Submit
6. Wait for approval (usually 24 hours)
```

### Task 3: Pay Monthly Maintenance
```
Time: 2-3 minutes

Steps:
1. Go to Maintenance Payments
2. Click "Pay Now" on pending item
3. Verify amount
4. Click "Pay"
5. Complete Razorpay payment
6. See green checkmark
7. Receipt saved automatically
```

### Task 4: Contribute to Event
```
Time: 3-4 minutes

Steps:
1. Go to Events
2. Choose event to support
3. Click "Contribute"
4. Enter amount
5. Click "Pay"
6. Complete payment
7. See updated progress bar
```

### Task 5: Check Latest Notices
```
Time: 1-2 minutes

Steps:
1. Go to Dashboard (see recent)
2. OR go to Notices section
3. Filter by priority if needed
4. Read important ones first
5. Click for full details
```

## 🆘 Troubleshooting

### Problem: Can't Login
**Solution:**
- Check email/password
- Clear browser cache
- Try different browser
- Contact admin with details

### Problem: Can't Submit Complaint
**Solution:**
- Ensure all fields are filled
- Check internet connection
- Try refreshing page
- Clear browser cache

### Problem: Payment Failed
**Solution:**
- Check internet connection
- Try different payment method
- Ensure sufficient balance
- Try again in few minutes
- Contact admin if persists

### Problem: Notification Not Received
**Solution:**
- Check browser notification settings
- Refresh page manually
- Check Notices section
- Log back in

### Problem: Filter Not Working
**Solution:**
- Refresh the page
- Clear filters and try again
- Check browser console
- Try different browser

## 📊 Understanding Statistics

### Complaint Stats
- **Total**: All complaints you've ever filed
- **Pending**: Just submitted, waiting for action
- **In Progress**: Admin is working on it
- **Resolved**: Fixed and closed

### Permission Stats
- **Total**: All requests you've made
- **Pending**: Waiting for approval
- **Approved**: You can use it now!
- **Rejected**: Need to resubmit or clarify

### Maintenance Stats
- **Total Records**: All payments (past and present)
- **Pending**: Still need to pay
- **Paid**: Already paid
- **Pending Amount**: Total money owed

### Event Stats
- **Progress Bar**: How close to fundraising goal
- **Collected**: Amount received so far
- **Target**: Total amount needed
- **Percentage**: Visual progress indicator

## 🎨 Understanding Colors

### Status Colors
```
🟡 Amber/Yellow  = Pending/Attention needed
🔵 Blue          = In Progress/Processing
🟢 Green         = Complete/Approved/Paid
🔴 Red           = Overdue/Rejected/Critical
⚪ Gray          = Not applicable/Closed
```

### Priority Colors
```
🔴 Red    = High (Read immediately)
🟡 Amber  = Medium (Should read soon)
🔵 Blue   = Low (General info)
```
